# Fuentes de servidor para OpenGraph

Plus Jakarta Sans, pesos estáticos Regular y Semibold. Descargadas el 12 de septiembre de 2026 desde el repositorio oficial:

- https://github.com/tokotype/PlusJakartaSans/blob/master/fonts/ttf/PlusJakartaSans-Regular.ttf
- https://github.com/tokotype/PlusJakartaSans/blob/master/fonts/ttf/PlusJakartaSans-SemiBold.ttf

SIL Open Font License 1.1 en `OFL-Plus-Jakarta-Sans.txt`. Se cargan con `lib/opengraph-fonts.ts` en las imágenes generadas del servidor. El navegador de la aplicación usa la versión WOFF2 de `public/fonts`.
